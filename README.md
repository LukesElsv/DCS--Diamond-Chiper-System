## 📖 Описание (RU)

**Diamond Cipher System V10.100** — это инструмент для стеганографического скрытия текста внутри визуальной структуры ромба с использованием индексной карты шумов.

### ⚙️ Принцип работы
1. Текст распределяется по слотам ромба.
2. Оставшиеся слоты заполняются шумовыми символами.
3. Индексная карта хранит позиции шумовых символов для последующего удаления.
4. Расшифровка восстанавливает текст, удаляя символы на указанных позициях.

### ⚠️ Важное предупреждение
* Эта программа **не предназначена** для совершения незаконных действий.
* Предназначена только для скрытия секретов между друзьями и личной переписки.
* **Не используйте** для защиты коммерческой тайны или критических данных в организациях.

## 🏷️ Статус разработки и схема версионирования
Логика присвоения номеров моим версиям построена по принципу **VX.Y** (например, V10.100).

* **Первая цифра до точки (X):** Означает номер глобального поколения с масштабными нововведениями.
* **Число после точки (Y):** Отражает процент завершенности текущего цикла разработки.

Например, версия V10.100 говорит о том, что цикл моего процесса создания и доработки десятого поколения полностью завершен. Поддержка таких версий заканчивается с выходом следующего крупного поколения. Однако, если новая версия еще не вышла, сборка со значением 100 остается актуальной только в том случае, если она имеет индекс `LS`. Если этого индекса нет, то, скорее всего, следующим релизом будет уже новое поколение. А если индекс `LS` присутствует, то с большей вероятностью при следующих обновлениях значение после точки просто пойдет выше 100.

# Diamond Cipher System V10.100 (Public) [EN]

## 📖 Description

**Diamond Cipher System V10.100** is a tool for steganographic text hiding inside a visual diamond structure using an index noise map.

### ⚙️ How It Works
1. Text is distributed across diamond slots.
2. Remaining slots are filled with noise characters.
3. Index map stores noise character positions for later removal.
4. Decryption restores text by removing characters at specified positions.

### ⚠️ Important Warning
* This program is **not intended** for illegal activities.
* It is designed only for hiding secrets between friends and personal correspondence.
* **Do not use** for trade secrets or critical data in organizations or companies.

## 🏷️ Development Status and Versioning Scheme
Version numbering follows the **VX.Y** format (e.g., V10.100).

* **First digit before the dot (X):** The global generation number with massive new features.
* **Number after the dot (Y):** Reflects the percentage of completion for the current development cycle.

For example, version V10.100 means the creation and refinement cycle for the tenth generation is fully completed. Support for such versions ends with the release of the next major generation. However, if the new version is not out yet, a build with the value 100 remains relevant only if it has the `LS` index. If this index is missing, the next release will most likely be a new generation. But if the `LS` index is present, it's highly likely that in subsequent updates the value after the dot will simply go above 100.

### 🔠 Letter Suffixes (Build Indexes)
I use letter indexes to indicate the specific nature of releases. Important note: these indexes can be combined in a single version. You can always find detailed information about a specific build, including the indexes themselves, directly in the app by clicking the **`i`** (info) button.

* 🛡️ **`LS` (Long Support):** These builds receive long-term support and continue to be maintained even after the release of the next major generation. This is the optimal choice for older devices or cases where the new version runs slowly. You can safely stay on an LS build and reach out to me for bug fixes specifically for it. If the version cycle is complete and the new generation is still not out, such releases can be supported by me for up to 7 years or more. Moreover, if a version with the LS index is released immediately with a 100 percent value, it is a sure sign that no major updates are expected for a very long time. In such exceptional cases, the index after the dot can exceed 100 percent, reaching values of 150, 200, and so on.
* ⚡ **`RS` (Rabbit Speed):** These versions include my intensive work on performance optimization. Improvements and acceleration can affect both standard operating mode and power-saving mode, or cover both scenarios at once.
* 👑 **`ADM` (Admin):** Used for administrative versions. They contain exclusive management functions and debugging tools. I distribute such builds exclusively to a limited circle of users or provide them on a paid basis.
